# ui —— 界面(内置那份的可改副本)

这个包带着**一整个界面**:`index.html` 就是内核自带的那份操作界面,原样打成一个包。

## 为什么预装它

界面是一个包,意味着:

- **改界面 = 改这个包**,不用碰内核、不用重新编译:编辑 `index.html`,然后
  `ngu pack` + `ngu install`,重启窗口就换上了;
- 界面是**一整个客户端**,不是格子 —— 它自己收事件、自己发命令,和任何包带来的
  界面走同一套 `ngu.send` / `ngu.on`;
- 卸掉它,窗口**回到内核里那份内置界面**(两者内容相同,所以卸载前后看起来一样,
  但你改过的那份就没了 —— 想保留就先备份)。

## 和内置界面的关系

- 预装后,窗口服务的就是**这个包里的副本**;内核里的那份是兜底。
- 因为副本是装的时候放好的,内核升级**不会**自动改它 —— 你的修改优先。想跟上新版,
  把你的改动合并进新的 `index.html` 再打包即可。

## 改它

```bash
# 1. 拿到当前这份
ngu ui ./my-ui          # 或直接编辑 ~/.nguruvilu/packs/ui-1.0.0/index.html

# 2. 改完打包、安装
ngu pack ./my-ui
ngu install ./my-ui-1.0.0.dshpack
```

界面在窗口打开时决定,所以改完要**重启窗口**才看得到。
