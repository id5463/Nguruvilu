# subagent —— 子代理

给对话带来 `delegate` 工具:把一个自包含的小任务交给一个**没有本次对话记忆**的全新
agent,只把它的答案带回来。大块的旁支调查因此不占你正在看的这份记录。

## 为什么它是一个包

`delegate` 的代码**编译在 `ngu` 里**,但"这次对话有没有它"由这个包决定:

- 内核只提供能力,包来启用 —— 内核不随能力增长而变化;
- 不装这个包,工具就不在表里,模型根本不知道它存在,也不占那份注意力;
- 你随时可以卸掉它,随时可以再装回来。

包里**没有二进制**。清单里那行 `"source": "builtin:delegate"` 是一个名字,不是一个
下载地址:装的时候不会去任何地方取东西。

## 装上之后

- 子代理看到**同样的工具表、同样的模型、同样的系统提示词** —— 它绕不过你给这个
  会话设的任何限制;
- 它**看不到这次对话**,所以任务要自己写全:路径、背景、什么算做完;
- 它不能反问;12 步之后一定停;再往下嵌套最多 2 层,防止一条指令长出一棵树。

## 卸载

```bash
ngu uninstall subagent          # 卸载,文件留着
ngu uninstall subagent --delete # 连文件一起删
```

或者在对话里让它自己来:`pack` 工具 `action: "unload"` —— 回合结束就生效,不重启。
