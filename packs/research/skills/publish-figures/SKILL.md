# publish-figures —— 可反复修订的出版级图表

一次性画死的位图,改一个数就要重画;**参数化脚本生成的矢量图**,改参数重跑
即可 —— 这是"可反复修订"的全部含义。

## 规则

1. **生成方式**:图表由脚本产出(Python/matplotlib、pgfplots、SVG 手参皆可),
   脚本进仓库,数据进仓库或有获取脚本 —— 任何人重跑得到同一张图;
2. **矢量优先**:PDF/SVG;确需位图(PNG)时按最终尺寸的 2 倍 DPI,
   不接受截图当图;
3. **图自明**:标题写**结论**(不是"结果图"),坐标轴带单位,图例不靠颜色
   单独区分(形状/线型同时编码 —— 色盲可读);
4. **风格统一**:同一文档内字号≥同文档正文的 0.8 倍、线宽一档(细 0.8pt /
   粗 1.5pt)、配色只用调色板里声明过的颜色;
5. **修订循环**:审稿意见/用户反馈 → 改**参数或数据**,不直接改图;
   图变了 → 重跑脚本 → 比对(必要时把新旧图并排说明差异)。

## 交付清单

- 图文件(矢量)+ **生成脚本** + 数据(或获取方式);
- 一句话说明:这张图的**结论**;
- 修订历史:改了什么参数、为什么(一段即可)。

## LaTeX 交接

- 稿件用 `standalone`/`pgfplots` 时图直接吃编译流程;用 PDF 图时
  `\includegraphics` 不缩放至失真,字号与正文匹配;
- 图号、交叉引用由 LaTeX 管,别把编号烧进图里。
