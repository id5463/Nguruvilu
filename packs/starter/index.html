Why is this the only place the proxy can be set?
Leave empty to connect directly. A value here is the only proxy used: the system HTTP_PROXY / HTTPS_PROXY variables are ignored, because a proxy set for another tool would otherwise reroute model traffic and fail with a TLS error.

How does the window and compaction behave?
Empty window means auto: the provider’s own number if it reports one, a built-in table for well-known models, otherwise a conservative 32k. When the prompt passes the threshold, the oldest messages are summarized and replaced — tool-call pairs are never split.
