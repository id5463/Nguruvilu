# chinese —— 中文界面

让模型用中文工作:回答、解释、错误说明、提问都用中文,而**代码、命令、路径、
标识符保持原样**。

## 装

**随程序预装**:装上就有,不用手动装。想手动来也行:

```
ngu install chinese-1.0.0.dshpack
ngu --assembly ~/.nguruvilu/packs/chinese-1.0.0/assembly.yaml
```

卸载:`ngu uninstall chinese`(文件留着)。界面文案会当场撤掉;已经写进对话的人设是
对话的一部分,不会被追回。

## 里面是什么

| 文件 | 做什么 |
|---|---|
| `soul.md` | 中文人设:语言、风格、做事方式 |
| `injections.json` | 两条常驻规则:用中文回答、不要开场白 |
| `look.json` | **界面文案**:把窗口里的按钮、栏目、占位符换成中文(纯数据,零代码) |

**零代码,全平台通用。**

## 为什么标识符不翻译

`cargo test` 翻译成「货物测试」就跑不起来了。语言和标识符是两件事,这个包把
它们分开 —— 读起来是中文,打出来还是原来那些字符。

## 为什么用两条注入而不是只靠人设

人设在一轮对话里会被后面的内容推远。注入规则是常驻的前缀,每轮都在最前面,
所以「用中文」这条不会因为对话变长而失效。

预算给了 10%,实际用不到 —— 两条规则加起来几十个 token。

## 自己改

`soul.md` 是纯文本,直接改。想让它更啰嗦或者更简短,改那份就行,不用碰别的。
